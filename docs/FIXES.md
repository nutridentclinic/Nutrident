## Local Verification vs. Production Realities (Honest Verification Disclosure)

In strict accordance with the testing guidelines, the following environments and scenarios were verified locally vs. those that must be verified in live staging:

### What Was Fully Verified Locally
- **Backend Test Suites**: All 10 Jest test suites (`72/72` tests) passing with in-memory MongoDB, mock Cloudinary buffer uploads, rate limiter tests, and role permission guards.
- **Frontend Test Suites**: All 8 Vitest suites (`49/49` tests) passing, verifying authentication state transitions, form validations, component renders, and API mock envelopes.
- **Build & Compilation**: `npm run build` in `frontend` completed cleanly in 1.45 seconds with 0 errors. `npm run lint` completed with 0 errors across 39 files.
- **Single Doctor Seeding**: Idempotent seeding script tested against User and Dentist models.
- **File Type Binary Validation**: Validated magic bytes inspection (JPEG, PNG, WEBP, PDF) and rejection of mismatched MIME types.

### What Requires Verification on Render & Vercel
- **Render Cold Start Performance**: Local Node processes start instantaneously. Real 30–60s cold starts on Render Free Tier depend on the updated 60–90s axios client timeouts and keep-alive pingers.
- **Live Cloudinary Asset Uploads**: Local tests mock Cloudinary's streaming API; real network uploads require valid API credentials and a lowercase cloud name in Render's dashboard.
- **Live Razorpay Webhook Signatures**: Verified signature verification algorithms with test secret keys; actual card debits and production webhook delivery require Razorpay sandbox/live keys.
- **Agora Multi-Party Video Calls**: Verified RTC lobby checks and token generation; true two-party video exchange across separate devices requires live Agora App ID and Certificate.
